```bash
uv sync

```

Или через Task:

```bash

```

## Офлайн-версия на телефоне и PDF

Опубликованный сайт поддерживает офлайн-чтение в мобильном браузере. Откройте сайт на телефоне при стабильном интернете или Wi-Fi и дождитесь загрузки. После этого основные страницы, поиск и картинки русской документации будут доступны из кэша браузера без мобильного интернета.

Чтобы было удобнее открывать документацию без сети, добавьте сайт на главный экран телефона:

- iPhone / iPad: Safari -> «Поделиться» -> «На экран "Домой"».
- Android: Chrome -> меню -> «Добавить на главный экран» или «Установить приложение».

Исходный японский PDF из раздела `files/` в офлайн-кэш не предзагружается, чтобы не занимать лишние десятки мегабайт на телефоне.

Офлайн-режим управляется в `mkdocs.yml`:

```yaml
extra:
  offline_pwa:
    enabled: true
    precache_images: true
    precache_files: false
    precache_print_page: false
```

Чтобы временно отключить PWA и очистить старый офлайн-кэш у пользователей после следующего открытия сайта, установите `enabled: false` и опубликуйте сайт заново. Чтобы не предзагружать все картинки, установите `precache_images: false`.

Собрать статический сайт:

```bash
task build
```

После сборки документацию можно читать без интернета из папки `site/`. Для полной работы навигации и поиска удобнее открыть её через локальный сервер:

```bash
python3 -m http.server 8091 --directory site
```

Затем открыть <http://127.0.0.1:8091/>.

Для PDF используется печатная версия, которую создаёт `mkdocs-print-site-plugin`:

```bash
python3 -m http.server 8091 --directory site
```

Затем открыть <http://127.0.0.1:8091/print_page/> и выбрать в браузере печать с сохранением в PDF.
